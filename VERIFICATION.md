# What was checked

Prepared 17 October 2026. **No native MATLAB or Octave runtime was available.** The MATLAB files have not been executed in MATLAB. Numerical results below come from an independent NumPy implementation of the same signal-processing equations and template matcher. These checks support the algorithm; they do not substitute for the supplied MATLAB self-test or confirm microphone compatibility on your machine.

## Executed numerical checks

- MATLAB syntax: all three `.m` files parsed without syntax errors using the Tree-sitter MATLAB grammar. This is a static grammar check, not MATLAB execution or API validation.
- Analysis / inverse reconstruction: tested lengths 8,000, 8,017, 16,000 and 17,321 samples, including non-hop-aligned boundaries. Maximum error for the primary random-signal case: `1.8041e-16`.
- Output signal length preserved; all tested output samples finite.
- Suppression gains bounded by 0.25 and 1; adaptive strength bounded by 0 and 0.8, within floating-point tolerance.
- DTW distance of an identical feature sequence to itself: zero.
- Both MFCC and Gammatone-PCEN modes returned `no speech` for exact silence and the tested stationary white-noise clip.
- All 12 supplied WAV files are mono 16-bit PCM at 16 kHz. Three examples per label are enrollment clips; the fourth speaking rate is held out.
- Nine clean enrollment clips plus nine noise-augmented enrollment copies produce eighteen templates. Augmentation uses only training recordings.
- The held-out START, STOP and LIGHTS clips were checked in raw, fixed 0.5 and adaptive modes, separately for both feature types: 18 condition/feature trials, based on only three unique test utterances. All 18 returned the expected command in this synthetic check.

## Signal results

| Command | Raw output SNR | Fixed output SNR | Adaptive output SNR |
|---|---:|---:|---:|
| START | 10.00 dB | 13.12 dB | 14.95 dB |
| STOP | 10.00 dB | 13.00 dB | 14.97 dB |
| LIGHTS | 10.00 dB | 13.07 dB | 14.79 dB |

These are whole-file, clean-reference SNR measurements, including silent intervals. The denoising stage is identical for both feature options. They show reduced signal error in these particular mixtures. Raw, fixed and adaptive recognition were all correct after training augmentation, so this tiny experiment **does not demonstrate a recognition accuracy advantage from adaptive processing**. MFCC DTW distance actually increased slightly after enhancement on these clips; the CSV retains that result.

`results/reference_scores.csv` contains every condition's decision, distance and output SNR. `reference_checks.json` contains numerical check values. `reference_signal_preview.png` and `reference_*.wav` were generated by the numerical implementation, not MATLAB.

## Limits of these results

The voice is Windows speech synthesis, not a human subject. Speaking-rate variants of one synthesis voice are highly correlated. Three unique commands, one noise mixture family and two negative clips cannot support a percentage accuracy claim, speaker-generalization claim, false-accept guarantee, embedded deployment claim, or real-time claim. Thresholds are prototype heuristics rather than statistically calibrated confidence measures. Human voice, microphone recording, unseen unknown words, new rooms, changing noise and MATLAB execution still require local evaluation.

The reference uses NumPy random number generation; MATLAB uses its own generator. The added noise will differ sample by sample even if both use seed 7. Expect similar behavior, not identical CSV numbers or plots. The independent implementation also uses its own training augmentation seed. The actual MATLAB run is authoritative for results on your MATLAB installation.

## Local MATLAB check

Open `RUN_DEMO.m` and click Run, or execute:

```matlab
speech_model('selftest');
result = speech_model('demo');
```

The self-test checks the implemented MATLAB STFT/inverse pair, finite output, length, gain/mix bounds, DTW identity and silence evidence. The demo then exercises audio loading, template fitting, both processing paths, recognition, plotting and file export. It saves MATLAB-generated results under `results/` with `demo_` and dashboard names, separate from the supplied `reference_` files. For the optional feature extractor, also run `speech_model('demo','','gammatone')`.
